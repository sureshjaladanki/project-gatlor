# Security disclosure

Gatlor accepts reports of security issues in this repository through GitHub private vulnerability reporting on this repo.

What to send: the affected tree or release, steps to reproduce, and impact. Do not open a public issue for an unfixed issue.

We read reports during EU business hours. There is no 24/7 cover.

This policy is how to tell us about a problem. It is not a statement that any product meets the Cyber Resilience Act.
